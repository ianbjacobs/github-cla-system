# Support

Use GitHub issues for reproducible defects, documentation problems, and feature requests. Include the
application version, deployment model, relevant configuration with secrets removed, webhook event
type, delivery ID, and sanitized structured logs.

Do not report security vulnerabilities publicly. Follow `SECURITY.md` instead.

This release candidate has no guaranteed service-level agreement. Production operators are
responsible for monitoring, backups, GitHub App credential rotation, and legal suitability.
